## Spark Order IQ

`spark-order-iq/` — a mobile-first PWA that turns a Walmart Spark offer
screenshot into TAKE, CONSIDER or SKIP against your own rules, and tracks the
day against an earnings goal. Decision support only: it never connects to Spark
and never accepts or declines an offer. See
[`spark-order-iq/README.md`](spark-order-iq/README.md).

```bash
cd spark-order-iq && npm install && npm run dev
```

A built copy for GitHub Pages lives in `docs/spark-order-iq/`
(`npm run deploy` refreshes it).
